{% load static %}{% comment %} Reusable PIFS head: compiled/purged Tailwind CSS + local HTMX + SELF-HOSTED Inter (NO CDN runtime, no third-party origin at all). Light + offline for mobile-first on slow Indian networks (ADR-003). Rebuild the CSS after template changes: `npm run build:css` (see README). Inter is self-hosted (static/fonts/) rather than fetched from fonts.googleapis.com. A render-blocking stylesheet on a third-party origin holds the document in a loading state until it settles, which never happens on a network that blackholes (rather than refuses) that origin — the page then never fires load/idle. Serving the font from our own origin makes page settle depend only on GoRefer being up. One variable woff2 (latin subset) covers all five weights: 400/500/600/700/800. {% endcomment %}
